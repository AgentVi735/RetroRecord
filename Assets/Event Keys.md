**Local Events**

* Lane Switch = LS00000000

  * lane setting (0,1,2,3) default is 00001111



**Global Events**

* Show Song Info = SI

  * active for 2/1 beats
* Effect = Ef-X (x == event key)

  * Flame effect = Fl

    * active for 1/4 beat
  * Spark effect = Sp

    * active for 1/2 beat
  * Smoke effect = Sm

    * active for 1/4 beat
* Light = Li-X (x == Lights\[] index)

  * Flashing = LiF-X

    * 1/1 = LiFW-X
    * 1/2 = LiFH-X
    * 1/4 = LiFQ-X
    * 1/8 = LiFV-X
    * 1/16 = LiFS-X
    * 1/32 = LiFT-X
    * 1/64 = LiFF-X
